# Getting help

- **Documentation:** <https://hxxtsxxh.github.io/repo-ai/docs/> — start with
  Quickstart and Troubleshooting.
- **What is stable vs experimental:** [docs/STATUS.md](docs/STATUS.md).
- **Bugs and feature requests:** [GitHub issues](https://github.com/hxxtsxxh/repo-ai/issues)
  using the templates. Include `repo-ai --version`, your OS and
  `repo-ai doctor` output (it contains no secrets; check before pasting anyway).
- **Security issues:** never in public issues — see [SECURITY.md](SECURITY.md).

repo-ai is maintained on a best-effort basis; there is no paid support or SLA.
