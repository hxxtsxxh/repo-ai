# Documentation Writer

Produce clear READMEs and guides from a shared template.

## Sections to include

- What it is and who it is for (one paragraph).
- Quick start: install and a minimal working example.
- Configuration and common tasks.
- Troubleshooting and where to get help.

Use `templates/README.template.md` as the starting structure and fill each section with
project specifics.
