# Safe Project Cleanup

Reclaim space by removing regenerable artifacts, carefully.

## What is safe to remove

- `__pycache__/`, `.pytest_cache/`, `*.pyc`, `build/`, `dist/`, `.mypy_cache/`.
- `node_modules/` (regenerated by `npm install`).
- Coverage output like `.coverage` and `htmlcov/`.

## How

- Prefer tooling: `git clean -nxd` first to preview, then `git clean -xd` for ignored files you
  confirm you want gone. Never pass `-f` blindly on an unfamiliar tree.
- Never delete `.env`, `.git/`, or anything not regenerable without asking the user.
- Show the user the list before deleting and let them confirm.

When in doubt, leave it and ask.
